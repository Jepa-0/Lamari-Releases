# Lamari playtest

Download **Lamari-Windows.zip** from the [latest release](https://github.com/Jepa-0/Lamari-Releases/releases/latest). Extract everything and open **Lamari.exe** with Steam running.

Host Game creates a named room. Your friend selects it in Join Game. Use separate Steam accounts. This early prototype uses Spacewar app ID 480.

Future updates are available through **Update** in the game menu. Each player's settings stay on their own computer.

This repository contains playtest downloads only. Source code is maintained privately.
